# 💰 Expense Tracker

A modern expense tracking web app built with Next.js, React, and Tailwind CSS.

## ✨ Features

- Add income & expenses
- Track balance
- Monthly statistics
- Responsive UI
- Authentication
- Dashboard analytics

## 🛠 Tech Stack

- Next.js
- React
- Tailwind CSS
- Drizzle ORM
- Neon Database

## 🚀 Run Locally

```bash
npm install
npm run dev
